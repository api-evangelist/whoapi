# WhoAPI

> WhoAPI Inc. (founded 2011, Mountain View CA) is a domain-intelligence API company providing WHOIS, domain availability, domain age, domain reputation/score, SSL certificate inspection, email score, email/IP blacklist checks, and website screenshots through a single key-authenticated REST endpoint (api.whoapi.com). Every request is an HTTP GET selecting a task with the `r` parameter and returning gzip-compressed JSON with a numeric `status` and human-readable `status_desc`. WhoAPI publishes no llms.txt of its own; this file is generated by API Evangelist from the provider's public documentation.

## APIs

- [WhoAPI Domain Intelligence API](https://whoapi.com/api-documentation/): Nine tasks selected via `r` — whois, taken, cert, domainscore, domainscore-check, emailscore, emailscore-check, blacklist, screenshot. Auth: `apikey` query parameter. Base: `https://api.whoapi.com/`.

## Conventions

- Auth: private API key as the `apikey` query parameter; one key per account; optional IP whitelisting.
- Errors: returned in-band with HTTP 200 — branch on the numeric `status` (0 = success, 1–42 = documented errors), never on the HTTP code.
- Rate limits: no `429`, no `Retry-After`, no `RateLimit-*` headers. Exhaustion arrives as `status` 16 (per-IP one-minute block), 17/18 (plan and high-usage limits) or 36 (monthly quota).
- Webhooks: the asynchronous `domainscore` and `emailscore` tasks accept a `webhook_url` query parameter; WhoAPI POSTs a JSON **array** of results and retries 5 times (5/15/30/60/60 min). No signature is published.
- No versioning, no pagination, no idempotency-key contract (all tasks are safe GET reads).
- No `/.well-known/` surface at all — security.txt, OIDC/OAuth metadata, api-catalog and A2A agent card all return 404.
